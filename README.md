# screenshot-api

A FastAPI service that captures desktop and mobile screenshots with Playwright,
uploads them to Google Cloud Storage, and removes them when they are no longer
needed.

## Screenshot endpoint

`POST /screenshot` accepts a list of URLs:

```json
{
  "urls": [
    "https://example.com",
    "https://example.org",
    "https://example.net"
  ]
}
```

A successful result contains the source URL and both uploaded image URLs:

```json
{
  "results": [
    {
      "url": "https://example.com",
      "desktop": "https://storage.googleapis.com/my-bucket/0123abcd-desktop.png",
      "mobile": "https://storage.googleapis.com/my-bucket/0123abcd-mobile.png"
    }
  ]
}
```

Desktop and mobile captures are independent. If one fails, the result preserves
the URL for any image that uploaded successfully and includes an `error` field.

## Cleanup endpoint

`POST /cleanup` accepts the complete response produced by `/screenshot`:

```json
{
  "results": [
    {
      "url": "https://example.com",
      "desktop": "https://storage.googleapis.com/my-bucket/0123abcd-desktop.png",
      "mobile": "https://storage.googleapis.com/my-bucket/0123abcd-mobile.png"
    }
  ]
}
```

Before deleting anything, the endpoint validates every image URL. It only accepts
HTTPS URLs on `storage.googleapis.com` for the configured `BUCKET_NAME`, using the
filename format generated by this app. Duplicate image URLs are deleted once, and
results containing only an error are skipped.

The endpoint sends up to 100 deletions in one Google Cloud Storage batch request.
For the usual three screenshot results, all six images are sent in one request.

Successful response:

```json
{
  "status": "completed",
  "attempted": 6,
  "deleted": 6,
  "batches": 1,
  "duplicates_ignored": 0,
  "skipped_records": 0
}
```

Google Cloud Storage batches are not atomic. If any deletion fails, `/cleanup`
returns HTTP 502 and notes that some deletions may have succeeded.

## Configuration

- `BUCKET_NAME`: Google Cloud Storage bucket used for screenshots.
- `CHROMIUM_PATH`: path to the Chromium executable.

Application Default Credentials must have permission to create and delete objects
in the configured bucket.

## Tests

Install the development dependencies and run the suite:

```bash
pip install -r requirements-dev.txt
pytest
```
